# ServiceFlow - Business Service Marketplace

A production-ready frontend web application for local businesses to list services and customers to book them.

## Tech Stack
- **React 19** + **Vite 6**
- **TypeScript** (Strict Mode)
- **Tailwind CSS 4**
- **Zustand** (State Management)
- **React Query** (Data Fetching & Caching)
- **React Hook Form** + **Zod** (Forms & Validation)
- **Axios** (API handling)
- **Framer Motion** (Animations)

## Features
- **Marketplace**: Browse and search for services with category filters.
- **Service Details**: Comprehensive view of service offerings and provider info.
- **Booking Flow**: Intuitive multi-step booking process.
- **Dashboard**: Personal area for managing bookings and viewing stats.
- **Authentication**: Secure Login/Signup with role-based profiles.
- **Responsive Design**: Optimized for all devices (Mobile-first).

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
